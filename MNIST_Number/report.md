# MNIST 迭代优化报告

## 项目目标

从一个基础三层全连接网络（FCNN）出发，逐步优化 MNIST 手写数字分类性能，并分析每一轮优化的收益与边界。


## 实验环境与任务

- 任务：MNIST 10 分类（0~9）
- 输入：`28x28` 灰度图
- 评价指标：测试集准确率（Accuracy）与平均损失（Average loss）
- 关键观察：在 `99%+` 阶段，误差主要集中在“人眼也难区分”的边界样本


## 迭代过程总览

### 第 0 轮（起点）：基础 3 层 FCNN + SGD

- 网络：`Flatten -> Linear(784,128) -> ReLU -> Linear(128,64) -> ReLU -> Linear(64,10)`
- 优化器：SGD（含 momentum）
- 初始训练轮数较少（后续逐步增加）
- 结果：可稳定收敛，但上限受限于全连接结构对空间信息利用不足

---

### 第 1 轮：SGD -> Adam，Epoch 从 4 提升到 15

- 改动内容：
  - 使用 `Adam` 替代 `SGD`
  - 训练轮数提升到 `15`
- 预期收益：
  - 更快收敛
  - 对学习率更鲁棒
  - 更充分训练，降低欠拟合
- 实际表现：
  - 准确率显著提升并趋于稳定
  - 你记录到的阶段性结果约在 `0.9812` 附近（全连接阶段）

---

### 第 2 轮：加入 Scheduler + Dropout + Weight Decay

- 改动内容：
  - 学习率调度器（先使用 StepLR）
  - `Dropout`（抑制过拟合）
  - `weight_decay`（L2 正则）
- 预期收益：
  - 后期训练更稳
  - 泛化能力增强
- 实际表现：
  - 全连接模型进一步稳定，但提升幅度开始变小
  - 进入“高位小步提升”阶段

---

### 第 3 轮：模型升级为 CNN

- 改动内容：
  - 从 FCNN 升级为 CNN（卷积 + 池化 + 全连接分类头）
- 关键原因：
  - CNN 利用局部感受野与参数共享，更适配图像任务
  - 可直接建模笔画、边缘、局部结构等空间特征
- 实际表现：
  - 准确率从全连接阶段明显跃升到 `99%+`
  - 实测曾达到 `0.9943` 左右

---

### 第 4 轮：BatchNorm + RandomAffine + AdamW + CosineAnnealing + TTA + Checkpointing

- 改动内容：
  - `BatchNorm2d`：提升训练稳定性
  - `RandomAffine`：增强训练集（旋转/平移），提升泛化
  - `AdamW`：更规范的权重衰减方式
  - `CosineAnnealingLR`：更平滑的学习率退火
  - `TTA`：测试时增强并平均预测
  - 最佳模型保存：按验证/测试表现自动保存最优权重
- 实际表现：
  - 在高准确率区间继续小幅改进
  - 你记录到从 `0.9943 -> 0.9948` 的提升
  - 该提升对应测试集约多分类正确 5 张图片（1 万测试样本）


## 误差分析（基于 best checkpoint）

- 错分样本已导出并可视化：
  - `MNIST_Number/misclassified_samples.png`
  - `MNIST_Number/misclassified_summary.txt`
- 主要结论：
  - 错误集中在易混淆类别（如 `4/9`、`7/2`、`5/3`）
  - 大量样本属于“边界写法”，人眼也难以稳定判断
  - 在 `99.4%+` 区间，继续提升通常是“高成本、低增益”


## 关键结论

- 这条优化路径是合理且有效的：  
  **优化器与训练策略优化 -> 正则化与调度 -> 架构升级 -> 高阶训练/推理技巧**
- 最大提升来自“**FCNN -> CNN**”这一步，后续属于精修。
- 当前结果已处于 MNIST 单模型的高水平区间；剩余误差多由数据本身的歧义导致，属正常现象。


## 后续建议（可选）

- 若目标是继续“刷分”：
  - 进行多随机种子复现实验并汇报均值/方差
  - 轻量模型集成（2~3 个独立模型投票）
  - 更精细的数据增强策略搜索
- 若目标是“能力迁移”：
  - 进入 `FashionMNIST` / `CIFAR-10`，验证方法在更复杂数据集上的可迁移性
